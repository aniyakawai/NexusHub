    System Management¶

    1 User Management¶

    1.1 What to Do If You Forget Your Login Password¶

    Forgot Password for Non-admin Users:

    • Email binding is set: if a user has set and bound an email, they can change or recover their password through the Change Password feature on the personal information page.
    • No email binding: If a user has not bound an email, an admin administrator can log in to the system, find the corresponding user on the User Management page, and directly change their password to help the user recover it.

    admin user forgot password:
    If email settings have been configured, you can click 【Forgot Password】on the login page to recover your password. If email is not configured, you need to restore the password to the default password by modifying the database. The steps are as follows:
    For online installation, enter the MaxKB container (if using the offline installation package, enter the pgsql container).

    docker exec -it maxkb bash

    Log in to PgSQL

    psql -Uroot
    Enter the MaxKB database
    \c maxkb;
    After connecting to the database, run the following SQL statement to reset the password of the admin user to MaxKB@123..
    update  "public"."user" set password='d880e722c47a34d8e9fce789fc62389d' where username='admin';

    Note: After recovering the admin password, configure an email first so that next time you forget your password you can directly use the 【Forgot Password】 feature to recover it.

    1.2 No Access Permission When Editing a User¶

    The gateway configuration did not allow the PUT method, resulting in a permission verification failure.

    2 Model Integration¶

    2.1 API Base URL Invalid When Connecting Ollama¶

    API Base URL Description:

    • API Base URL format: the IP address of the service where http://ollama resides:the Ollama port number / .

    Note: The API Base URL cannot use 127.0.0.1 or localhost.

    Obtain the IP address of the Ollama service:
    Run ip addr on the server where Ollama is installed to obtain the server's IP address. If the Ollama server IP address is 172.26.186.35, the API Base URL is: http://172.26.186.53:11434

    Ensure the service is accessible:
    The MaxKB container must be able to access the Ollama service normally. Access the Ollama API Base URL in the MaxKB container and make sure it returns the 【Ollama is running】status.

    Ollama Configuration File Modification:

    After confirming the above, add the Ollama model in MaxKB.
    For installing Ollama on Windows, you can further refer to: Tutorial for Local Deployment of Ollama + MaxKB on Windows.

    2.2 Verification Failure When Connecting an Image Generation Model¶

    The cause is an incorrect parameter component type. Specifically, the "guidance_scale" component type is set incorrectly. The solution is to change the "guidance_scale" component type to a slider and set the step size to 1.

    2.3 Verification Failure When Connecting XInference Speech Synthesis Model¶

    The error message is as follows: Error code: 400 - {'detail': '[address=0.0.0.0:4215, pid=41292] Model not found, uid: XXX'}.
    The cause may be an incorrect model name or version. Resolution steps:

    • Check the model name: use a curl request in the container to see whether the corresponding model name is returned.
    • Check the XInference version. If the version being used is v1.3.0.post2, this version is a test version and may be unstable. We recommend switching to a more stable version, such as the latest stable release of XInference.

    2.4 Adding a Model Fails with a Connection Error¶

    This is usually caused by network connection issues. Troubleshooting ideas:

    • Check the firewall settings: confirm whether the firewall restricts the relevant ports. If it does, open the port so that the container can access the network normally.

    • Check the container network configuration: confirm whether there is network connectivity inside the container. You can try running a network test command inside the container (such as ping or curl) to check network connectivity.

    2.5 Adding a Model Fails with a Balance-Related Message¶

    Check model availability on the corresponding platform to ensure the model has balance available for calls.

    2.6 Error When Adding a Model: 'str' object has no attribute 'model_dump' or Invalid API-key provided¶

    Verify the API Base URL and key: ensure the API Base URL is available and correctly configured, and the corresponding API Key is valid and has sufficient permissions. If it is a third-party proxy service, you may need to contact its provider to confirm service status and configuration requirements.
