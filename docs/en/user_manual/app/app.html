    Agent Overview ¶

    1 Feature Overview¶

    MaxKB provides preconfigured templates and components, enabling you to quickly create a basic Q&A agent or perform advanced orchestration of complex business processes to build a dedicated AI assistant.

    • Folder management: Agents are managed through folders. Up to three levels of subfolders can be created under the root directory. Corresponding agents can be created in each level of folder. Folders support resource authorization; regular users can only view authorized folders, and when authorizing a folder, the existing sub-resources under it can also be authorized.
    • Status feature: the agent displays 【Unpublished】 or 【Published】 status (the first time an agent is created it is saved as unpublished, which is the unpublished status), as well as the publication time.

    After the agent is created, go to the agent page to view the agent overview and perform related settings and connections.

    Note: Agent access and chat users are X-Pack features.

    2 Agent Types¶

    Simple Agent: provides relatively basic features and setting options, with complete basic functionality that meets most basic Q&A needs; it is suitable when you need to launch an Agent quickly.

    Advanced Agent: Supports users in creating workflows that conform to business logic, including but not limited to judgment components, question optimization, function libraries, and built-in tags, to meet various needs such as question classification and sensitive word retrieval. It is suitable for scenarios that require complex logic and custom workflows.

    3 Template Center¶

    In the 【Template Center】, you can select the desired agent. You only need to configure basic parameters such as the model and knowledge base in the orchestration interface to quickly complete the agent's workflow deployment and realize the intelligent implementation of typical business scenarios.

    To enrich template resources and drive the sustainable development of the product ecosystem, MaxKB sincerely invites community users to participate in building the Template Center and share technical achievements;

    Contribution path: Refer to the template development guidelines provided by the official team to develop agent or knowledge base workflow templates for MaxKB;

    Submission method: After development is complete, submit the template to GitHub Official Repository. The project team will review it according to the process, and once approved it will be listed on the MaxKB Template Center for all community users to use.

    4 Agent Operations¶

    4.1 Going to Chat¶

    In the agent panel, click the Go to Chat button to jump to the chat page.

    4.2 Settings¶

    Click 【Settings】 on the agent panel to go to the agent settings page and configure the agent.

    4.3 Resource Authorization¶

    Click 【Resource Authorization】 on the agent panel to authorize the application to the corresponding users.

    4.4 Viewing Related Resources¶

    Click 【View Related Resources】 on the agent panel to view the related resources of the agent. You can search by name, creator, and type.

    4.5 Triggers¶

    Click 【Trigger】 on the agent panel to add a scheduled or event-triggered trigger for the agent.

    Creating a Trigger: click 【Add】 to create a trigger.

    • Trigger Name: the name of the trigger, used to identify different triggers and their trigger conditions.
    • Description: Detailed description of the trigger and usage notes.
    • Type:
      • Scheduled Trigger: tasks can be executed monthly, weekly, daily, or at intervals, and can also be triggered based on Cron expressions.
      • Event trigger: that is, a Webhook trigger. When you create an event trigger, the system automatically generates a URL and Bearer Token, allowing the caller to send HTTP requests (with the Token in the Header) carrying request parameters to trigger the corresponding workflow.
    • Task execution: the task executed by the trigger, which requires entering the corresponding parameter content.

    4.6 Transfer To¶

    Click 【Move to】 on the agent panel to move the agent to another folder of agents under the same workspace.

    4.7 Copy¶

    Click 【Copy】 on the agent panel, set the name and description of the copied agent, then save to copy the agent.

    4.8 Export/Import¶

    The agent supports export. After export, the file name is: Agent Name .mk.

    For agents of the advanced orchestration type, the exported content includes the parameter settings of all nodes in the workflow and the function contents; the knowledge base and model information selected in workflow nodes are not exported.

    On the Agent page, click 【Import Agent】 to import an agent file (with the .mk file extension).

    4.9 Delete¶

    Click the 【Delete】 button on the tool panel to delete the agent. After clicking Delete, a confirmation dialog appears; click OK and the agent is deleted.

    Note: After a tool is deleted, it cannot be recovered.

    5 Batch Select¶

    Click batch selection to select multiple agents for move or delete operations.
