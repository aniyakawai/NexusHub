    Tool¶

    1 Feature Overview¶

    MaxKB allows users to obtain and query data, perform logical decisions, extract information, or handle other scenarios through various tools according to their business needs, and invoke these during agent orchestration to meet various complex business requirements.

    • Shared tool: after the System Administrator creates a shared tool in [Shared Resources], it can be authorized to specified workspaces.
    • All tools: users can create tools. Other users can view, use, and maintain them after Resource Authorization.

    Tools are managed through folders, and up to three levels of subfolders can be created under the root directory. Corresponding tools can be created in each folder level. Folders support resource authorization; regular users can only view authorized folders, and when authorizing a folder, you can authorize the existing sub-resources under it.

    Note: Shared Resources is an X-Pack feature of the Enterprise Edition.

    Creating tools supports creating tools, creating Skills, creating MCP, creating data sources, importing to create, and adding from the tool store.

    2 Create Tool¶

    2.1 Dependency Installation¶

    If the tool implementation requires installing third-party dependency packages, you can install them using the pip command in the MaxKB container.

    # Enter the MaxKB container

docker exec -it maxkb bash



# Install third-party dependencies with pip, e.g. pymysql, by running the following command

pip install pymysql

    2.2 Tool Creation¶

    Click 【Tool】 to open the Create Tool page.

    • Tool Name: the tool's logo and name, for easy identification. The tool logo can be customized and uploaded after saving.
    • Description: Detailed description of the tool and usage notes; displayed in the component list of the Advanced Agent.
    • Startup parameters: the parameters required for a tool to run, such as an API Key. Separating startup parameters from input parameters lets you focus only on input parameters in the workflow and also prevents sensitive information from being leaked.
    • Input parameters: The input parameters of a tool. The data types of the parameters include string, int, dict, float, array, and boolean. You can assign custom values or reference parameters.
    • Tool Content: supports custom Python tool code that can reference input variables; also supports automatic tool script generation, which can directly generate the corresponding Python code based on the tool name, description, and parameters.
    • Output parameters: The result returned by the Python code execution.

    After writing the Python code, click [Debug] to verify the code's functionality. After debugging, click [Create] to complete the creation of the tool. A successfully created tool is [Disabled] by default.

    Enabled tools can be called as components in the Advanced Agent by clicking Add Component -> Tool, or through the Tool of the AI Chat component.

    3 Creating a Workflow¶

    Click 【Workflow】 and enter the workflow name and description.

    • Workflow Name: the workflow name, for easy identification.
    • Description: Detailed description of the workflow and usage notes; displayed in the component list of the Advanced Agent.

    Enter the workflow editing page, where you can add components or other tools to orchestrate the workflow.

    Basic Information: used to configure the basic data of the workflow tool, including the tool's input and output parameters. Each workflow tool has exactly one such node.

    Node Settings:

    • User Input: the input parameters of the workflow. The parameter data types include string, int, dict, float, array, and boolean. They can be custom assigned or reference parameters.
    • Output parameters: The result returned by the workflow execution.

    Start: serves as the starting point of workflow execution; all subsequent nodes begin their flow from this node.

    Global variables: input parameters set in the workflow basic information, serving as the global variables of the entire workflow.

    For other components, refer to: Basic Components

    4 Creating Skills¶

    Note: Due to environmental constraints and security considerations, Skills only supports Skills triggered by Python.

    Click 【Skills】 to open the Create Skills page.

    • Name: the name of the Skills, for easy identification.
    • Description: detailed description of Skills and usage notes; it will be displayed in the component list of the Advanced Agent.
    • Startup parameters: the parameters required for the Skills to run, such as an API Key. Separating startup parameters from input parameters lets you focus only on input parameters in the workflow and also prevents sensitive information from being leaked.
    • Skills File: drag and drop or select the Skills ZIP file, up to 100 MB in size. Supports re-upload and download.

    Newly created Skills are Disabled by default. After enabling a Skill, you can reference it in the Skills of Advanced Agent -> AI Chat.

    5 Create MCP¶

    Click 【MCP】 to open the Create MCP page.

    • MCP Name: the name and Logo of the MCP, for easy identification. The MCP Logo can be customized and uploaded after saving.
    • Description: detailed description of MCP and usage notes.
    • MCP Server Config: fill in the MCP Server configuration parameters in JSON format. Call the tools in the MCP service via the SSE/Streamable HTTP protocol.

    Newly created MCPs are Disabled by default. After enabling an MCP, you can reference it in the MCP of AI Chat, or call it in the Advanced Agent by clicking Add Component -> MCP Call to add it as a component.

    6 Create Data Source¶

    Click 【Data Source】 to open the Create Data Source page.

    • Name: the data source logo and data source name, for easy identification. The data source logo can be customized and uploaded after saving.
    • Description: Detailed description of the data source and usage notes; displayed in the component list of the Workflow Knowledge Base.
    • Startup parameters: the parameters required for a data source to run, such as Token, Secret, etc. Separating startup parameters from input parameters lets you focus only on input parameters in the workflow and also prevents sensitive information from being leaked.
    • Input parameters: The input parameters of a data source. The data types of the parameters include string, int, float, and array. You can assign custom values or reference parameters.
    • Function content: write custom Python data source code, which can reference input variables.
    • Output parameters: The result returned by the Python code execution.

    Newly created data sources are Disabled by default. After enabling a data source tool, you can add the data source to create a knowledge base in the Workflow Knowledge Base by clicking Add Component -> Data Source.

    7 Create from the Tool Store¶

    The tool store is a feature module in the MaxKB system that helps users extend the system's capabilities.

    Tools in the tool store are mainly categorized into web search, database query, API tools, content processing, message push, and translation tools, among others.

    Users can directly select the tools they need in the store without manual development or complex integration, which significantly improves the efficiency of calling tools.

    To enrich Tool Store resources and drive the sustainable development of the product ecosystem, MaxKB sincerely invites community users to contribute tools and share technical achievements:

    • Contribution path: Developers can follow the tool development guidelines provided by the official team to develop tools for MaxKB (such as API integration tools and local functionality tools);
    • Submission method: After development is complete, submit the tool code to GitHub Official Tool Repository. The project team will review it according to the process, and once approved it will be listed on the MaxKB Tool Store for all community users to use.
    • Co-building the development ecosystem: tools contributed by the community can not only help more users solve real problems, but also promote the diversified development of the MaxKB tool ecosystem, forming a positive cycle of "user needs - tool development - ecosystem improvement".

    After a tool is added, once you configure the startup parameters (such as database connection information, API Key, etc.) and enable it, it can be called in the Advanced Agent.
