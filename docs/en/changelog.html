    Changelog

    1 Release Notes¶

    Version Description: Like other excellent open-source projects, MaxKB will keep releasing a new feature version every month; when an urgent or serious Bug is encountered in a feature version, a minor Bug-fix version will be released promptly.
    The MaxKB version numbering convention is: v Major.Feature.Bug-fix version, for example:

    • v2.0.1 is a bug-fix release after v2.0.0
    • v2.1.0 is a feature release after v2.0.0
